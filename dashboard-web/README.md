# RAG Wazuh Dashboard

Professional security operations dashboard with AI-powered threat analysis and intelligence.

## Features

### Main Dashboard
- **Real-time Statistics**: Total reports, high-risk alerts, average risk scores, 24h activity
- **Risk Trend Charts**: 7-day threat landscape visualization with average risk scores
- **Severity Distribution**: Pie chart showing threat categorization breakdown
- **Reports Table**: Filterable list with severity, risk scores, affected hosts, and AI summaries

### AI-Powered Threat Analysis Report
The detailed report view provides unique value beyond standard Wazuh or OpenCTI reports:

1. **AI-Generated Executive Summary (TL;DR)**
   - One-sentence summary of the entire incident
   - Automatically generated by LLM for quick understanding

2. **Attack Timeline Reconstruction**
   - AI reconstructs the attack progression chronologically
   - Shows tactics, techniques, hosts, and timestamps
   - Provides narrative description of each step

3. **Predictive Threat Intelligence**
   - AI predicts likely next actions by adversary
   - Confidence levels for each prediction
   - Reasoning behind predictions

4. **AI-Generated Response Playbook**
   - Automatic incident response workflow
   - Organized by phases: Containment → Eradication → Recovery
   - Step-by-step actionable instructions

5. **Business Impact Assessment**
   - Operational risk analysis
   - Data integrity risk evaluation
   - Domain-wide risk assessment

6. **Enhanced IOC Collection**
   - 8 types of IOCs: IPs, users, hashes, domains, file paths, registry keys, processes, commands
   - Automatically extracted from alerts

7. **MITRE ATT&CK Mapping**
   - Techniques with IDs and tactics
   - Linked to OpenCTI knowledge base

## Technology Stack

### Frontend
- **React 18** with TypeScript
- **Vite** for fast development and build
- **Tailwind CSS** with dark theme optimized for SOC environments
- **Recharts** for data visualization
- **React Router** for navigation
- **Lucide React** for icons

### Backend
- **FastAPI** for high-performance API
- **PostgreSQL** for data storage
- **Psycopg2** for database connectivity

## Development

### Prerequisites
- Node.js 20+
- Python 3.11+
- PostgreSQL 16+

### Local Development

1. **Install frontend dependencies**:
```bash
cd dashboard-web
npm install
```

2. **Install API dependencies**:
```bash
cd api
pip install -r requirements.txt
```

3. **Configure environment**:
```bash
cp .env.example .env
# Edit .env with your database credentials
```

4. **Start development servers**:

Terminal 1 (Frontend):
```bash
npm run dev
# Runs on http://localhost:3000
```

Terminal 2 (API):
```bash
cd api
python main.py
# Runs on http://localhost:8000
```

## Docker Deployment

### Build and run with Docker Compose:
```bash
# From project root
docker compose up -d dashboard
```

### Access the dashboard:
- Frontend: http://localhost:3000
- API: http://localhost:8000
- API Docs: http://localhost:8000/docs

## API Endpoints

### Reports
- `GET /api/reports` - Get all reports with filtering
- `GET /api/reports/{id}` - Get specific report by ID
- `GET /api/reports/recent?limit=10` - Get recent reports
- `GET /api/reports/high-risk?min_score=70` - Get high-risk reports
- `GET /api/reports/stats` - Get dashboard statistics
- `GET /api/reports/timeseries?days=7` - Get time series data

### Health
- `GET /` - Root health check
- `GET /api/health` - Detailed health status

## Design Philosophy

The dashboard follows modern SOC best practices:

1. **Dark Mode First**: Reduces eye strain in dimly lit SOC environments
2. **Clear Visual Hierarchy**: Critical information prominently displayed
3. **Predictive Analytics**: AI-powered forecasting of threat evolution
4. **Actionable Intelligence**: Not just detection, but response guidance
5. **Professional Aesthetics**: Clean, minimalist design focused on data

## Differentiation from Wazuh/OpenCTI

### vs Wazuh Dashboard
- AI-powered threat correlation across multiple alerts
- Predictive intelligence for next adversary actions
- Automated incident response playbooks
- Business impact assessment

### vs OpenCTI Dashboard
- Real-time alert integration from Wazuh
- Risk scoring with AI
- Timeline reconstruction from raw alerts
- Customized response workflows based on environment

### Unique Value
The RAG (Retrieval-Augmented Generation) approach combines:
- Real-time Wazuh alerts
- OpenCTI threat intelligence knowledge base
- LLM reasoning and generation

This creates reports that provide both **detection** (Wazuh), **context** (OpenCTI), and **insight** (AI), making it a comprehensive threat analysis platform.
